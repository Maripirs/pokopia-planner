# Pokopia Planner

A grid planner for Pokopia islands: paint ground and objects, label places, and plan underground levels (tracks, platforms, stations, entrances).

Live site: https://maripirs.github.io/pokopia-planner/

Layouts save in your browser. Use **Copy code** / **Paste code** to back them up or move them between browsers. On a browser's first visit, `layouts.json` loads the starter layouts.
